## Сделано

- Общая проверяемая операция удаления/отмены: точный заказ, точная связанная запись исполнителя, проверка суммы, возврат двух частей баннерного минуса. Предварительная проверка всех ссылок, откат всей операции при ошибке записи.
- Новые заказы связываются с исполнителем и материалами по постоянным идентификаторам, не по позиции списка или переименованному имени. Отмена ищет заказ по oid во всех клиентах. Открытый калькулятор сохраняет ссылки на выбранных клиента и исполнителя и проверяет их перед добавлением.
- Копейки сохраняются (раньше общий форматтер округлял до одной цифры и мог потерять её из-за двоичного представления float). Удаление сохраняет отрицательный баланс/переплату клиента и исполнителя.
- Старые неоднозначные записи не сопоставляются по сумме/дате наугад: выдаётся понятное сообщение без изменения расчётов. Полностью восстановить отсутствующую старую связь без исходных данных невозможно.
- Очистка видимой истории архивирует записи, сохраняет долг, прибыль и ссылки для отмены связанных заказов. Удаление строки прибыли — по oid, без поиска по одному имени/дате.
- Закупка использует тот же выбор специальных материалов, что и расчёты; суммы с копейками, отрицательная прибыль, рулоны. Отказ сохранения откатывает закупку.
- Основной JSON пишется во временный файл, flush/fsync, затем os.replace. Ошибки больше не скрываются. Неизвестные поля верхнего уровня сохраняются. Повреждённый файл сохраняется отдельно до восстановления; при отсутствии исправной резервной копии не заменяется пустыми данными.
- Android: UchetActivity переопределяет getAppRoot на /files/uchet_runtime, чтобы штатная очистка распакованного кода не удалила прежний /files/app/business_data.json. Python копирует старые JSON/резервные копии в /files/uchet_data, сохраняет оригиналы и не заменяет уже перенесённый файл. Проверена модель миграции, повторного запуска, очистки runtime и ошибки копирования; Android-установка пока не проверена.
- В APK исключены данные клиентов, резервные копии и тесты; package.name/domain сохранены, версия 1.1.
