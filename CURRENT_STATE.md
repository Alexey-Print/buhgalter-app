# «Учёт» — что сделано и как устроено (на 11.11.2026)

Приложение для учёта типографии Алексея: долги клиентов, мои долги исполнителям (Олег, Малевич), заказы банера/плёнки, остатки рулонов, прибыль. Kivy/Python, Android.

## Где что лежит

- Рабочая ветка: `claude-fixes-2026-11-05` — весь актуальный код. В `main` не сливалось.
- Ветка ChatGPT `audit-safe-fix-2026-11-05` и PR №1 — прежний аудит, не менялись.

## Приложение на телефоне
- Новое: «Учёт», пакет `com.aleksey.uchet2`, версия 4.12 (в коде уже 4.13, APK 4.13 ещё не собран). Номер версии виден внизу главного экрана.
- Старое: «Uchet» (`com.aleksey.uchet`, 1.0) — стоит рядом, не удалять, пока не перенесены все данные.
- Данные из старого переносятся вручную (решение Алексея), импорт/экспорт базы есть в окне «Чистая прибыль».
- Подпись постоянная (SHA-256 сертификата 25401616e1362d236c7c2a84102fdac674ce250b7ac6ae26fdc6d56d16b61e01): новые версии ставятся поверх без потери данных.
- Пароль ключа — у Алексея на бумаге и в переменной GitHub `UCHET_KEY_PASS`. Он виден в старых журналах сборки; Алексей решил оставить как есть.

## Как собрать новую версию
1. Поднять `version` в `buildozer.spec` и `APP_VERSION` в `main.py` (одинаково; проверяется тестом).
2. Commit в `claude-fixes-2026-11-05` со словами `[build apk]` в описании → GitHub сам прогоняет проверки, собирает, подписывает, проверяет подпись и кладёт APK по постоянной ссылке. Около 3–13 минут (инструменты хранятся между сборками).
3. Без `[build apk]` сборка не запускается. Собирать только когда Алексей попросит.
4. В этом чате собрать APK нельзя (закрыт доступ к серверам Android) — только через GitHub.

## Что исправлено и добавлено (относительно 1.0 / сборки ChatGPT 1.1)
- Удаление заказа точно возвращает долг клиента, долг исполнителя, списание банера и прибыль.
- Оплата, переплата и обнуление переплаты не создают ложную прибыль.
- Служебные карточки (остаток, белый, чёрный банер) имеют постоянную роль; имя клиента («Черный Сергей», «Олег») на расчёты не влияет.
- Ошибка записи не закрывает приложение: всё откатывается, «Не сохранено, повторите».
- «Обнулить долг» исполнителя убирает историю в архив; связанного исполнителя нельзя удалить.
- «Сброс всех данных» сначала делает проверенную копию базы (папка backups/before_reset).
- Повреждённая база: отдельные копии, экран с объяснением вместо закрытия.
- Журнал операций (было → стало по каждой сумме) и перепроверка базы при каждом запуске — чтобы находить расхождения вроде Сашиного.
- Взаимозачёт: если человек и клиент, и исполнитель под одним именем (Дима Малевич), долги гасятся друг о друга автоматически, прибыль не меняется.
- Калькулятор: запятая = точка, двойная «Отмена шага» отменяет один шаг, база не перезаписывается на каждую цифру.
- На экране суммы в целых рублях (внутри считается до копейки); имя клиента и цвет рулона не пропадают при длинных числах.
- Окно рулона: поля парами, «СОХРАНИТЬ» над клавиатурой, клавиша ↵ сохраняет; исправлено закрытие приложения при сохранении рулона.
- «ВСЕ ЗАКАЗЫ»: у каждого дня кнопка «+ ДОБАВИТЬ» — дописать забытую позицию в заказ этого дня (обычный расчёт, дата = выбранный день, в расчёте жёлтая надпись «ДОПИСЬ В ЗАКАЗ ЗА …»). В APK 2.5.
- Карандаш у клиента → «ИСПРАВИТЬ ЗАКАЗЫ»: список по датам, нажать на позицию → поправить размер, кол-во, цену, цену исполнителю (у допобработки — сумму). Старая позиция отменяется и записывается новая с той же датой и на то же место; долг клиента, исполнителя, списание банера и прибыль пересчитываются. При сбое — всё как было. В APK 2.5.
- Расчёт: кнопка «+ ТАКСИ» рядом с допобработкой. Поля «Я ЗАПЛАТИЛ» и «КЛИЕНТУ» (пусто = столько же). Кнопки «ВСЁ КЛИЕНТУ» (в прибыль не идёт) и «ПОПОЛАМ» (моя половина вычитается из прибыли). В долг клиенту — сумма клиенту, прибыль меняется на разницу (хранится как print_cost, mode='taxi', без исполнителя). Исправляется через «ИСПРАВИТЬ ЗАКАЗЫ». Работает и через «+ ДОБАВИТЬ» за прошлый день. В APK 2.5.
- «СКОПИРОВАТЬ ВСЁ»: текст со значками (📋 💰 📅), у каждой позиции цена за м² отдельной строкой, такси и допобработка одной строкой. Жирный шрифт при копировании невозможен — буфер обмена только обычный текст. В APK 2.5.
- Список «ИСПРАВИТЬ ЗАКАЗЫ»: строки мелкие, как в «ИСТОРИИ ЗАКАЗОВ», сами подстраивают высоту под текст (не наезжают при крупном шрифте телефона). Окно карандаша сделано компактнее, текст в полях по центру. Окно карандаша: поле «СКОЛЬКО ОТДАЛ (ОТНЯТЬ)» — частичная оплата, как на первом экране. В APK 2.6.
